# donasionline (Donasi Online)
Akuntansi dana ZIS untuk platform donasi di ERPNext 16: bagan akun, dimensi Dana/Kampanye,
kontrol keseimbangan per Dana, dan mesin jurnal otomatis donasi. Rancangan: `docs/psak/05-*.md`.
Semua aturan adalah USULAN provisional sampai F1-F29 dijawab akuntan/ahli syariah.
